# Mô hình IPO hiển thị sản phẩm
Input:
id, name, price, img, description, type, deleted
Output:
type sản phẩm
img, name, button xem thêm
Process:
B1: Tạo 1 card trong productView.js
B1.1: Tạo các thành phần tag name trong card
B1.2: Gắn id vào các thành phần tag name trong card
B1.3: Tạo các class của từng tag name
B1.4: vd: muốn custome card tạo file component card.scss 
B1.5: Viết các class vừa tạo thêm các thuộc tính scss để làm đẹp
B1.6: Tạo ra khuôn làm đẹp 
B1.7: Sử dụng các khuôn này trong file View.js
=> Thành quả tạo được 1 card hoàn chỉnh
